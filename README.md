# MathLab — GitHub Pages

## Жүктеу тәртібі

1. ZIP архивін компьютерде толық шығарыңыз.
2. GitHub репозиторийінің негізгі бетінде Add file → Upload files таңдаңыз.
3. **index.html** файлын репозиторий түбіріне жүктеңіз. ZIP архивін жүктемеңіз. index.html қосымша қалташаның ішінде тұрмасын.
4. Commit changes батырмасымен сақтаңыз.
5. Settings → Pages → Build and deployment бөлімінде Source: Deploy from a branch таңдаңыз.
6. Branch: main, Folder: / (root) таңдап, Save басыңыз. Егер негізгі тармақ атауы басқа болса, файл жүктелген тармақты таңдаңыз.
7. GitHub Pages берген сайт сілтемесін ашыңыз. HTML файлының GitHub-тағы код беті сайттың өзі емес.

## Құрамы

- index.html — барлық мазмұн, формула, сызба, тест, кері байланыс және навигация бір файлда.
- .nojekyll — қосымша генераторсыз статикалық файлдарды жариялау белгісі.
- README.md — осы нұсқаулық.

Сайт үшін index.html файлын жүктеу жеткілікті. Басқа екі файлды да сол деңгейде жүктеуге болады. Құрастыру, сервер және қосымша кітапхана қажет емес.

7–11-сыныптардың оқу материалдары сақталған. Сыныптарға, тақырыптарға және OlympLab нұсқаларына сілтемелер # арқылы ашылады, сондықтан жоба атауына тәуелді емес.

Тест жауаптары мен кері байланыс жазбалары сол браузерде сақталады. GitHub Pages мұғалімге жауаптарды жіберетін сервер қызметін атқармайды.

Тексеру: барлық JavaScript блоктары синтаксистік тексеруден өтті; сыртқы ресурсқа тәуелділік жоқ; оқу деректері түпнұсқамен бірдей. Браузердегі визуал және интерактивті тексеру осы ортада қолжетімсіз. Бұл жинақ GitHub-қа автоматты түрде жарияланбаған.
